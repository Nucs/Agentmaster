# Test fixture — `sample-crash.dmp.gz`

A small, **non-sensitive** crash dump for smoke-testing the analysis tools end-to-end. It is generated by
`../scripts/makedump.exe` — a tiny purpose-built crasher (`../scripts/makedump.cpp`) that dereferences a
`0xDDDDDDDDDDDD0000` "freed-fill" pointer a couple of frames deep, reproducing the exact **use-after-free
access-violation signature** of the real Agentmaster bugs this skill was born from (`Rcx = 0xDDDD…` +
`faultData = -1` non-canonical). It is a dump of that throwaway process only — **no user data** — so it is
safe to commit. Compact type (stacks + modules + exception, ~38 KB raw / ~7 KB gz), not full-memory.

## Run the smoke test

```bash
cd .claude/skills/debug-dumps
cmd /c scripts\build.bat                 # once: build the tools (+ makedump)
gunzip -k test/sample-crash.dmp.gz       # -> test/sample-crash.dmp   (or regenerate: scripts\makedump.exe test\sample-crash.dmp)

BASE="K:\\source\\Agentmaster\\.claude\\skills\\debug-dumps"
MSYS_NO_PATHCONV=1 ./scripts/dumpexc.exe    "$BASE\\test\\sample-crash.dmp"
MSYS_NO_PATHCONV=1 ./scripts/dumpwalk2.exe  "$BASE\\test\\sample-crash.dmp" "$BASE\\scripts"
MSYS_NO_PATHCONV=1 ./scripts/dumpourscan.exe "$BASE\\test\\sample-crash.dmp" "$BASE\\scripts" makedump
```

## Expected output (the toolchain is healthy if you see all three)

- **dumpexc** → `ExceptionCode = 0xC0000005`, `ExceptionInformation[1] = 0xFFFFFFFFFFFFFFFF` (non-canonical),
  and a register `Rcx = 0xDDDDDDDDDDDD0000` — the freed-fill signature. Teaches: "a `0xDDDD…` register ==
  use-after-free" (SKILL.md §6).
- **dumpwalk2** → an ordered walk `makedump!FaultDeep (makedump.cpp:49)` → `makedump!wmain` — with
  **source line numbers**, because `scripts\makedump.pdb` sits in the `<bindir>` you passed. Proves DIA
  symbolization works against a matching PDB.
- **dumpourscan** → `#FAULT makedump.exe +…`, then a scan listing `wmain` + CRT frames symbolized, and a
  module histogram. Proves the "our frames" scan + the optional module filter (`makedump`).

If symbolization shows only `+0xOFFSET` with no function/line, the PDB didn't match the binary (rebuild
`makedump` via `build.bat`, or check `<bindir>` — SKILL.md §2).

## Notes

- The raw extracted `sample-crash.dmp` is git-ignored (regenerate any time); only the compressed
  `sample-crash.dmp.gz` is committed.
- To exercise the **full-memory / `Memory64List`** path that real WER dumps use, edit `makedump.cpp` to OR
  in `MiniDumpWithFullMemory` and rebuild (produces a ~30 MB dump). The tools read both range formats.
- Real Agentmaster crashes are in `%LOCALAPPDATA%\CrashDumps\` and are analyzed identically — but they are
  full-memory dumps of a live session (they DO contain process memory), so do **not** commit those.
