## Agentmaster 0.8.0

**0.8.0 is a stable release: the whole 0.7.x pre-release line plus a large final batch, now the default for everyone.** Since the last stable (0.7.0), Agentmaster went **mobile through Telegram**: every working session is a topic on your phone with its whole conversation, a message there is queued as that session's next prompt, Claude's questions are answered with a tap, and a Search topic finds and reopens old sessions. On the PC, the Agent Manager moved behind the tab strip's **Home** button beside a **fleet side panel**; the prompt queue became the **Prompt Queue Runner** in every build, with delivery that is atomic and verified; **presets** run Claude Code on other models and providers; an **AI search** reads your sessions and reopens them into the right window; and **Show Transcript** renders any conversation as Markdown. It also fixes what made the line worth graduating: five UI freezes (the latest a session hopping between two tabs 175,000 times), a launch that hung with no window, two crash classes, a memory leak in every terminal, turns that never continued after an API error or a restart, and much of the CPU a fleet of hundreds of tabs cost. This build becomes the new default **Latest**; the highlights are below, followed by the complete per-version changelog since 0.7.0.

## Highlights

### New
- **Your fleet in Telegram.** Connect a bot of your own under **Settings → Messaging** and every Claude tab that is not idle, in every window, becomes a topic of its chat. A topic wears the tab's title and color, shows the session's state as its icon, and holds the whole session: your prompts, Claude's replies with their Markdown (tables included) rendered, and a status card with buttons that stays at the bottom. Anything you type in a topic is queued as that session's next prompt (`/steer` sends it into the running turn), a multiple-choice question is answered with a tap or in your own words, the screen comes as text or a picture, and a session can be forked, restarted or started fresh in any folder and window. The 🔎 Search topic finds and reopens old sessions, and a pinned message keeps the fleet's counts, your tags and the tabs used last at the top. Only your own Telegram account is answered.
- **The Agent Manager is a page, beside a fleet side panel.** The pinned Manager tab became a page behind the tab strip's **Home** button, which turns into a jump-back arrow to the tab you came from. A side panel docked beside the terminal shows this window's (or every window's) session cards over the summary of the session you are in, with a **+** that launches a session at the click.
- **The Prompt Queue Runner, in every build.** Queue prompts for a session and each goes out when the previous turn completes (per session **Auto** or **Paused**, plus one Pause for all). Delivery is atomic and verified (filled, read back, then submitted), so a queued prompt can no longer stack, double-send or merge into your unsent draft; an automatic send waits for a settled ready state, and **Esc** parks the runner until you reply.
- **AI search for your sessions.** The Sessions page's **AI** toggle takes a request in plain words ("the session where I fixed the tab drag crash"). A hosted Sonnet 5.5 searches every session, reads each candidate, shows the ones that fit with the evidence for each, and can resume or fork one into the window and place you choose. The same agent answers in Telegram's Search topic.
- **Presets: Claude Code on other models and providers.** OpenRouter (MiMo, Kimi, Qwen, GLM), Xiaomi MiMo, NanoGPT, your own RunPod vLLM endpoint or any Anthropic-compatible URL appear in every launch and fork menu, with keys kept in Windows Credential Manager and a session keeping its preset through resume, restart, fork and `/handover`.
- **Read any conversation.** **Show Transcript** renders a session as Markdown in a reading view, **Copy ▸ Transcript** copies it at five detail levels, and a session's summary now spans the whole conversation: a fork's parent, a plan restart, a `/clear` or `/handover` predecessor.
- **Park, dock and batch-close tabs.** **Deactivate ▸** shuts a session's claude down while its tab keeps its place, ready to resume when entered (this tab, others, left / right, a folder's, all); a tab dragged onto another window's strip docks there; and **Close ▸ Of Same Folder** closes a folder's sessions across windows in one confirm.
- **Interrupted work goes on.** A turn cut off by a crash or shutdown reads **Error** instead of a ready Idle, a turn that died on an API error continues when its session is resumed, and after a restart the restored tabs that were busy start by themselves.
- **Install and identity.** A portable copy's first launch offers a real per-user install (desktop icon, Start menu, folder right-click menu, Apps & Features, no admin), and the app's executable is now **`Agentmaster.exe`**.
- **Taskbar and display.** A red count on the taskbar button and a framed window preview show where unread sessions wait; **Software rendering** gets around the NVIDIA driver's ~62-terminal limit; hidden tabs stop drawing and give back their GPU memory; and **Tab size** sets the tabs' width, font and height.
- **And more:** a folder filter in the Sessions page, unsent prompts that travel with a fork, tag filter chips on the Triage Board, a **MOST RECENT** sort that keys on turns, and a **session database** preview (off by default) that also answers `agentmaster search` and `agentmaster sql` in any shell.

### Fixes
- **Five UI freezes.** A Remote Desktop theme storm, a "window stops accepting clicks" dispatch wedge, the Agent Manager rebuilding on every change, an 8-hour freeze on a tab switch, and a session hopping between two tabs that ran the same conversation (175,433 times in under three days, leaking a tab overlay at every hop) are gone.
- **Crashes and hangs.** The WinUI tab-drag crash class, a crash on a mouse move over a just-opened tab, and a launch that hung forever with no window (the GPU driver deadlocking at startup) are fixed.
- **Large fleets cost far less.** Ambient animations no longer keep XAML redrawing the whole window, the side panel draws only the cards near the view, the transcript scanner follows one file-system watch instead of re-walking every project folder, and a memory leak in every terminal is fixed (each URL scan and Find leaked 144 bytes: 52 MB after 17.5 hours on a ~700-tab install).
- **Prompts that never arrived.** Prompts that Claude Code 2.1.277+ refused to submit (an "invisible" character in the box) are cleaned with Claude's own rule, non-ASCII prompts no longer arrive garbled, and a queued local command (`/add-dir`, `/model x`) no longer fails the queue and pauses its runner.
- **Sessions reading the wrong state.** No more Running for hours after a turn ended, a Running → Waiting → Running flicker on ~29% of prompts, an Error that outlived a retry, or a compaction dropping a running session to Idle.
- **Hooks and Ctrl+G.** Hooks no longer time out at launch and exit (they ran through Git Bash and your `BASH_ENV`; on Claude Code 2.1.139+ they now run PowerShell directly), and Claude Code's Ctrl+G editor works again with an over-long PATH.
- **Tabs that behaved badly.** Orphaned console sessions (a claude whose terminal host was killed) are reaped, closing a tab no longer starts a dormant neighbor's Claude, Deactivate no longer turns parked tabs into plain shells, and a restarted session is no longer archived seconds later.

### Worth knowing when you upgrade from 0.7.0
- ⚠️ **The Prompt Queue Runner is on in every build.** New sessions start in **Auto**, so a prompt still Pending from an earlier Debug Mode run, or a `/handover` briefing that was never delivered, is sent once its session is open and settled. The default is under **Settings → Prompt Queue Runner**.
- ⚠️ **Alt+Left and Ctrl+Home are Windows Terminal's again.** The tab strip's **Home** button is the way into the Agent Manager.
- ⚠️ **The executable is `Agentmaster.exe`.** A `WindowsTerminal.exe` forwarder ships beside it, so old shortcuts, pins and scripts still work.
- ⚠️ **One line appended to a transcript.** To let a turn that died on an API error continue, Agentmaster appends Claude Code's own rewind line before the resume (never a deletion, never while a claude runs the conversation). It is the one change Agentmaster makes to a transcript; turn it off under **Settings → Sessions**.
- ⚠️ **Telegram carries what it shows.** The bot is off until you set it up. Once on, your sessions' text, and the terminal's screen when you ask for it, travel through Telegram, whose bot chats are not end-to-end encrypted.

## 0.8.0
### New

- **Your fleet in Telegram (opt-in).** A Telegram bot you create runs inside Agentmaster. Set it up under **Settings → Messaging**: turn on **Run the Telegram bot**, paste its token (kept in Windows Credential Manager, never in a file or a log) and your numeric Telegram user id; the bot reads nobody else's messages. First turn on **Threaded Mode** for the bot in @BotFather's Mini App (Bot Settings → Threads Settings). Every Claude tab that is not idle, in every window, then becomes a topic of the bot's chat, named with the tab's color square and title, its state shown as the topic's icon (⚡️ running · 💬 waiting · ❓ needs approval · ‼️ error · 🏁 done · ☕️ idle). A topic carries the WHOLE session: its history is replayed first (paced within Telegram's limits), then it follows live. A new tab or fork gets its topic at once, a topic follows its tab through `/clear` and `/resume`, and an idle session's topic leaves after a grace period (10 min by default) with one line in the chat's main view; `/pin` keeps a session from ever going idle. A message sent while Agentmaster was closed is asked about before it is queued.
- **The conversation, readable on a phone.** Your prompts arrive as "👤 You · 14:02 · typed at the PC" (or 📱 from the phone, ⚙ runner) under the session's title. Claude's replies come as rich messages in which Markdown tables, headings and code render, each reply quotes the prompt it answers, and only a turn's final message makes a sound. A topic shows the conversation only, or every remark and tool call as well (`/verbose` per topic; **Topics show the work** sets the default). Every title the bot prints wears the tab's color and opens its topic, and a renamed or recolored tab posts one line saying so.
- **Drive a session from its topic.** A message you type in a topic is queued as the session's next prompt and sent when the session is ready, whatever the Prompt Queue Runner's mode (a parked tab is started for it); a reaction shows where it stands (✍ queued → 👨‍💻 picked up). `/steer <message>` sends it NOW, into the running turn. A status card stays the topic's last message: the state and since when, the title, folder · branch · model · effort · context, a queued prompt, your unsent draft at the PC and Claude Code's recap. It rings when the session exits, errors or needs you. Its **⚙️ Session** page holds ⑂ Fork, 🆕 New Session, 🔄 Restart Session (🔧 Resume Session in an error), the runner, the queue, 📌 Pin, 📄 Transcript, 🖥 Screen Text and 🖼 Screen Image (the terminal's screen drawn as a picture); a tapped button stays busy until its work is done. The tab menu's actions are `/commands` too (`/help` lists them), and Claude Code's own commands are queued like prompts.
- **Answer Claude's questions from Telegram.** A multiple-choice question (`AskUserQuestion`) arrives as ONE question card: tap an option, write your own answer or add a note; several questions are tabs with the PC's review and Submit, multi-select keeps the order you ticked, previews show inline or as a picture, and 💬 Chat about this, ✖️ Cancel (the PC's Esc) and a plain reply are there too. The answer is composed exactly as the PC composes it, and the PC's own dialog stays usable (the first answer wins). It works through a hook Agentmaster adds while the bot runs (Claude Code 2.1.139 or later; a session started before the bot was on needs 🔄 Restart Session). A `/add-dir` sent from a topic turns its "Add directory to workspace" dialog into a card whose buttons answer it, and "Yes, for this session" is picked by itself after 60 s.
- **Search, start and find sessions from the chat.** The 🔎 Search topic runs the AI search in a conversation of its own: an answer lists the sessions with a quote of the evidence, and a tap on one offers Resume, Resume 📌 (pinned) or Fork into a tab on the PC. `/idle` lists idle tabs with Wake buttons, `/search <words>` asks from any topic, and `/search_tab` brings Search to the top. Opening a NEW thread starts a new session through a short wizard: its folder (recent and most-used lists, or a typed path; a missing folder can be created), optionally a model or preset, and the window (by default right after the newest tab working in that folder). The thread's name becomes the session's title, and renaming the thread renames the session. A pinned message at the top of the chat shows the fleet's counts, the dedicated topics, every tag with its open tabs, and the ten tabs used last. Every app start posts a note in Search saying which version came up and whether the last run closed normally. Optionally, a second "secretary" bot posts the prompts you type at the PC as your own messages.
- **The AI search reads, explains and reopens.** It now reads every session before showing it (new `read` and `grep` tools) and gives each shown session a one-line reason, drawn as a quote under its title in the Sessions page. A request opens with the agent's plan ("I'll 1. … 2. … 3. …"), shown while it works, and ends with a descriptive answer and the likely next step. It can list your windows and tabs, resume or fork a session into a named window right after the right tab (in the background unless you ask), and deactivate one tab. With several windows open it asks which one, and it asks before cutting off a running turn.
- **A thinking level for the AI search.** The strip's `thinking off` (beside `ctx 15k / 200k`) rotates off → low → medium → high → xhigh → max on a click: global, remembered, and applied live to the running conversation. "Off" is now really off on Sonnet 5.5 (Claude Code leaves the field out for that model, and the API then thinks by default).
- **A turn that died on an API error continues.** When a turn ends on an API error ("Connection lost mid-response", an overload, a dropped stream), **Restart session**, **Deactivate**, a window restore and the Sessions page's **Resume here** now let Claude Code continue that turn instead of sitting at the error. Agentmaster appends Claude Code's own rewind line past the failed response first; nothing is deleted, and nothing is written while a claude runs the conversation. With `CLAUDE_CODE_RESUME_INTERRUPTED_TURN=1` in Claude Code's settings the turn goes on by itself. **Settings → Sessions → "Continue a turn that ended in an API error when its session is resumed"** (on by default).
- **Busy tabs wake up after a restart.** A window restore used to start only the tab each window opened to, leaving every other session that was mid-turn dormant until clicked. Now each restored tab that was running, needed approval or was in error at the restart starts by itself once every window's focused tab has launched, paced across all windows (one every 500 ms, at most 4 per 10 s).
- **The session database (preview, off by default).** **Settings → Sessions → SESSION DATABASE** keeps every Claude Code session on the machine in one DuckDB file per profile, served by a helper process (`agentmaster-sessiondb.exe`). **Shadow** builds it and compares it with today's search in the log; **On** runs the Sessions page's content search on it and, from the next start, gives the AI search ten database tools. It also answers `agentmaster search <words>`, `agentmaster sql "SELECT …"` and `agentmaster sessdb status|resync|rebuild|stop` from any shell, and serves an MCP server (`agentmaster-sessiondb.exe mcp`) you can add to Claude Code. The first build reads every transcript in the background (37 minutes for 11 GB of transcripts on the machine it was measured on).
- **The side panel's + card opens with its folder list ready**, right under the path box and never over it or Launch; Esc closes the list, and a second Esc closes the card.

### Fixes

- **The October 14 freeze.** One conversation running in two or three tabs (a `/resume` of an open conversation plus Restart copies) made its session hop between the tabs: 175,433 times in under three days. Each hop leaked a tab overlay and made the Agent Manager rebuild its board with columns that were never freed, until the window stopped answering clicks with the machine at 98% RAM. Now one tab hosts a conversation (another tab running it reads "same conversation as another tab · unlinked"), each claude's own heartbeat drives only its own state, the board keeps its columns and refills them, and rebuilds space themselves by what they cost.
- **A memory leak in every terminal.** Every URL scan after new output and every Find leaked 144 bytes, an upstream Windows Terminal bug: 381,056 leaked blocks (52 MB) after 17.5 hours on a ~700-tab install. Fixed at its source.
- **The side panel at hundreds of tabs.** On ~700 tabs its cards made up 81% of what XAML walked on every frame (about 250 ms of UI thread each second). A card now draws its rounded corners without a composition node of its own, and only the cards near the view exist: the list is virtualized.
- **AI search answers that missed sessions.** After a pause it could answer "nothing found, still being indexed" (it had searched a partial index), and it looked back only 90 days. It now waits for one shared index that is never freed, searches every session by default, greps with a sharper prefilter, runs the deep search over every session in 7 s instead of 79 s, and follows a seven-step search procedure tuned on an evaluation of real searches: mean recall went from 55% (the app as it was) to 100%.
- **A queued `/add-dir` or `/model x` failed the queue.** A local command writes no prompt line, so 15 s after the Prompt Queue Runner delivered one it was judged lost: marked Failed, and the session's runner paused. Its transcript echo now proves the delivery, and no "lost" verdict is passed while a menu is open.
- **The Sessions page could hide content matches.** When ripgrep refused a batch of files, the page read it as "no file matched" and hid every match in them; those files are now searched in-process.
- **"Launch Claude" needed a double-click** while its model menu was open: the menu's dismissal ate the press. One click launches now, and a double-click launches once.
- **The Settings card cut off its tabs.** It is 15% wider, so all ten tabs ("Claude" and "About" included) fit on one row.

## 0.7.10
### New

- **The Home button is also the way back.** On the Agent Manager page, the tab strip's **Home** button turns into a jump-back arrow (↶) while a session this window hosts is selected — usually the tab you came from — and a click returns to that tab, after which it is Home again. Its reply is now held to one short sentence.

## 0.7.9
### New

- **The Agent Manager is a page behind the Home button.** The pinned, non-closable tab 0 is gone: the Triage Board, Explorer Tree and Prompt Queue open from the tab strip's **Home** button (left of the `<` scroll arrow), and clicking any tab, **Jump Back**, a card double-click, a toast click or Ctrl+Tab leaves the page. A window can now hold zero tabs — closing the last tab, deactivating the focused one, or closing onto a strip of dormant tabs shows the page instead of closing the window or waking a session — and a window closed while on the Manager reopens on it.
- ⚠️ **Alt+Left and Ctrl+Home are back to their Windows Terminal defaults.** **Alt+Left** moves pane focus left again (it jumped to the Manager tab) and **Ctrl+Home** is unbound again (it toggled the Manager), so both reach your shell and Claude exactly as in stock Windows Terminal. Home and Jump Back are the way in and out.
- **A fleet side panel beside the terminal.** A panel that belongs to the window, not to any tab, docks **left** of the terminal (⇄ flips it): this window's session cards on top — state dot, folder color, unsent-draft dots, timing, tag ribbons, a filter box, the board's sort, and a per-window **LOCAL / GLOBAL** toggle — over the full summary of the session you are working in. Clicking a card peeks at another session until you click back into the terminal; ⌖ (on by default) scrolls the list to the selected tab's card; **Sum** hides the summary so the cards fill the panel, and each card then shows the tab's rich session card beside the panel on hover; and **+** opens the Agent Manager's launch row in a card right at the click. Both splitters drag-resize per window (the last resize seeds new windows), and « collapses the panel to a thin strip.
- ⚠️ **The prompt queue ships in every build, as the Prompt Queue Runner.** The Tests Autorunner and its Auto Testing pane — until now only in dev builds or with Debug Mode on — are renamed the **Prompt Queue Runner** and the **Prompt Queue** and are part of every release: queue prompts for a session and each one is sent when the previous turn completes. A session has two modes, **Paused** and **Auto** (Semi-auto and its confirm are gone); the toolbar's global Pause is one state that every window shows, and each tab's badge then reads, for example, "Auto (Off globally)". An automatic send now waits until the session has held a ready state for 40 s, restarting on every status change, and never types into a parked or not-yet-started tab — the queue resumes when the tab starts. New sessions start in **Auto** (change the default under **Settings → Prompt Queue Runner**), so a prompt still Pending from an earlier Debug Mode run, or a `/handover` briefing that was never delivered, is now sent once its session is open and settled.
- **Presets — Claude Code on other models and providers.** Named presets appear after a separator in every **Open New Session Here** / **Fork session** menu and the Launch button's hover menu: MiMo Pro / Flash, Kimi K3, Qwen3.8 2.4T and GLM-5.3 through OpenRouter; MiMo through Xiaomi's own API; MiMo V2.6 Flash, GLM-5.3 Flash and DeepSeek V4.1 Flash through NanoGPT; a model on your own RunPod vLLM endpoint; or any custom Anthropic-compatible endpoint. The list starts empty — **Settings → Presets → TEMPLATES** adds a template with one click (or every tested one at once), and until you do, every launch menu offers **Add presets…**. Each field inherits from Agentmaster's env, then Windows', then the template (shown as gray placeholders); keys are kept in Windows Credential Manager and handed only to that one `claude`; a session keeps its preset through resume, restart, fork and `/handover`; and a preset that can't launch is refused, never silently downgraded to your Claude login. Templates marked "not tested yet" (Xiaomi, NanoGPT, RunPod) are added only by their own Add.
- **AI search in the Sessions page.** An **AI** toggle inside the search box turns it into a request line — type "the session where I fixed the tab drag crash" and press Enter: a hosted **Sonnet 5.5** runs the page's own search, fills the table with the sessions that fit, best match first, and states its answer in one sentence under the header. A follow-up ("only the open ones") refines the list, Escape stops a request, and ⊘ starts over. It drives one hidden `claude.exe` per Agentmaster process on your own Claude Code login — never listed among your sessions, compacting itself at 500K tokens, and ended 10 minutes after no page uses it (the conversation then resumes from a digest).
- **Show Transcript — any conversation as a reading view.** **Show Transcript** (below Copy in every session menu) renders the conversation as Markdown in a card over the window, one tab per detail level, opening at the level you last picked in any window. Each turn's tool calls fold into one summary row ("▸ 4 tool calls: Bash ×3, Write") with **Expand all**, every "session N" of a forked or restarted chain links to that session's heading, and ↵ toggles line wrapping. Esc, a click outside or a tab switch closes it.
- **Copy ▸ Transcript at five detail levels.** Every session copy menu's **Transcript ▸** copies the conversation as Markdown at **Minimal** (your messages and each final reply) · **Compact** (+ compactions, your answers, slash commands, each subagent's brief and report) · **Default** (+ every tool call on one line) · **Full** (+ each command, its first output line, durations) · **Max** (+ every written file's content) — including the sessions it was forked or restarted from and the subagents it spawned. It replaces the flat Transcript and Transcript Followup items.
- **The summary shows the whole conversation.** A session's summary now lists every earlier session it continues — a fork's parent, a plan-mode restart, a `/clear` predecessor, a `/handover` origin — numbered straight through as one conversation, with a thin separator after each earlier part (click it to copy that session's id); the ⏮ toggle hides them.
- **Unread work on the taskbar.** A red number on Agentmaster's taskbar button counts the sessions waiting for you — exactly the tabs whose status dot wears the red flash ring, across every window — and the taskbar and Alt+Tab preview of each window holding an unread tab gets a frame in the flash-ring color until you've read it. A turn that finishes in the selected tab of a background window now rings and counts until you return to that window. Both switches are under **Settings → Notifications → TASKBAR**.
- **Rendering settings.** **Settings → Behavior → RENDERING** adds **Software rendering** — every terminal drawn on the CPU instead of the GPU, applied live in every window — the escape hatch from the NVIDIA driver's ~62-terminal limit, past which a new tab could stay black; and tabs you can't see now stop drawing and give back their GPU memory after 60 s hidden (both on by default, the delay adjustable).
- **Tab size.** **Settings → Tabs & Overlay → TAB SIZE** sets the tab width mode (Windows Terminal's own setting, Equal width, Fit to title or Compact), the minimum and maximum width, the title's font size and weight, and the minimum height, live in every window.
- **Deactivate ▸ gets the Close submenu's scopes.** Beside Deactivate Tab / Other Tabs / All Tabs come **Tabs to the Left**, **Tabs to the Right**, **Of Same Folder** and **Other of Same Folder** — the folder scopes reach every window. Unlike Close they ask nothing first, and a turn still running in a parked session is cut off.
- **Unsent prompts travel with you.** A fork types the source's unsent prompt into its own box (never sent), including every `[Pasted text #N +M lines]` block, rebuilt from the real pasted content Agentmaster now remembers per session; **Copy Current Prompt** likewise hands over the pasted text instead of the label. **Settings → Sessions → "Copy my unsent prompt into a forked session"** (on by default).
- **Sorting and cards.** A **MOST RECENT** sort (board, side panel, tree) keys only on turn boundaries, so a session grinding through tool calls or a background team no longer floats above the one whose turn just started or ended; a new session or fork now starts at the top; and the timing line reads "created 4d1h, active 2m4s ago".
- **"Specify a model…" remembers your last pick.** The prompt opens pre-filled with the model you last committed — in every window and after a restart — and Enter / Escape now work in its box. The Launch folder picker also grows with the window, up to 90% of its height.

### Fixes

- **A launch that hung forever with no window.** The NVIDIA driver's initialization could deadlock against the first known-folder lookup at startup — no window appeared, and every relaunch silently failed. The folders are now resolved before the GPU is touched, and a watchdog ends a hung launch after 25 s so the next one can start.
- **A crash on a mouse move over a just-opened tab.** After a fork (or any new tab), a mouse move could reach the terminal before it had a text buffer and crash the app. A terminal now starts in its first sizing pass and ignores mouse input until it has started.
- **An 8-hour UI freeze on a tab switch.** Switching onto a tab whose conversation repeated a prompt's opening words hundreds of times could spin the summary jump resolver forever; it is bounded now, and that input resolves in 3 ms.
- **A slow UI on large fleets.** On a 555-tab window the UI thread was busy 43–60% of a core, largely redrawing for animations. The ambient animations — the unsent-draft dots, the spark crown, the unread blink — now run on the Composition API, so no XAML storyboard keeps a 60 Hz full-tree frame walk going; the side panel edits its cards in place instead of re-creating them; periodic engine work copies only what it reads; never-opened tabs no longer run a handler on every layout pass; the Tags panel opens at once (it read 2,000+ files on the UI thread, over 5 s); and the transcript scanner, which re-walked every project folder on every pass (~35% of a core), is now driven by a single file-system watch.
- **Sessions reading the wrong state.** A session no longer strands **Running** for hours after a turn ended quietly (the reader parked mid-history on a large transcript); no longer flickers Running → Waiting → Running on ~29% of prompts (the scanner read the previous turn's end before the new prompt reached the transcript); and a turn cut off by a crash or shutdown now reads **Error** instead of a ready Idle — the queue used to send its next prompt straight past it — returning to Running when the turn resumes. A compaction no longer drops a running session to Idle.
- **Hooks timing out at launch and exit.** Every hook ran through Git Bash plus your `BASH_ENV` (measured at up to 15 s) while Claude waited, and Claude's 1.5 s SessionEnd budget cancelled deliveries. On Claude Code 2.1.139+ the forwarder runs PowerShell directly (median 0.36 s), every hook carries a timeout, and SessionEnd gets 5 s.
- **Claude Code's Ctrl+G: "Edit quit unexpectedly (exit code 1)".** Past 8,191 characters of PATH, cmd.exe finds no command at all — and Claude runs its editor through cmd.exe. Agentmaster now trims the copy of PATH it hands each session (duplicates first, then only directories that provably don't exist); a healthy PATH and your registry are never touched.
- **Prompts Claude Code 2.1.277+ refused to submit, and garbled Hebrew.** Newer Claude cancels an Enter when the box holds an "invisible" character; everything Agentmaster types is now cleaned with Claude's exact, context-sensitive rule first (emoji, Indic and Persian joiners and a Hebrew line's direction marks survive). Non-ASCII prompts no longer arrive garbled (`שלום` came out `╫⌐╫£╫ò╫¥` and was recorded twice), and a non-ASCII Windows user name no longer breaks hook delivery.
- **Deactivate and Restart unbinding tabs.** A Deactivate could turn every parked tab into a plain PowerShell tab, and half of the Restarts measured were archived seconds later, because the dying claude's last signals re-stamped the record. A parked tab is now exactly a window-restored tab — entering it resumes the conversation — the closing claude's late signals are ignored, and the tab strip stays where it was.
- **The tab strip.** Selecting a far-off tab scrolls the strip to it; a tab opened from another tab's menu no longer scrolls the strip back to where you were; the strip can be scrolled away from the selected tab again; a long title ends in "…" inside its tab instead of running under the next one; and moving the focused tab no longer marks its neighbor read.
- **Closing a tab no longer starts another Claude.** Focus used to land on the neighbor, and a dormant neighbor then started its own `claude.exe`; focus now goes to the nearest tab that starts nothing, or to the Agent Manager page.
- **/compact, /clear and resume.** The context size updates the moment a compaction finishes, and summaries, copied transcripts, titles and prompt lists span the whole session across compactions (they hid ~99% of the pre-compaction prompts). External sessions follow a `/clear`, and a `/clear` in a managed tab keeps the tab managed, so Deactivate and Restart work on it again.
- **Summaries.** A message typed while Claude works now appears in the summary (Claude stores it as an attachment, not a user line), and a fork with no messages yet shows the conversation it was forked from — in Show Transcript, Copy, Summary and the tab hover card — instead of nothing.
- **Smaller fixes.** Unsent drafts are read under Claude's fullscreen renderer (`CLAUDE_CODE_NO_FLICKER=1` / `/tui fullscreen`) without mistaking Ctrl+G's editor for the input box, and **Send now** on a dormant tab keeps the prompt queued instead of losing it.

## 0.7.7
### New

- **Deactivate a tab — park a session without closing it.** A new **Deactivate ▸** tab-menu submenu (**Deactivate Tab · Other Tabs · All Tabs**, right above **Close ▸**) shuts down a session's `claude`/`codex` while the tab keeps its place, title, color, queue, and autorunner — exactly the dormant, waiting-for-focus state a freshly reopened window's tabs sit in. Focusing or activating the tab resumes the conversation. It's the non-destructive sibling of Close: park it instead of ending it, with no confirm.
- **A portable copy installs like an app — or stays portable.** A portable (unzipped) copy's **first launch now asks where Agentmaster should live**: install it to your **user folder** (`%USERPROFILE%\.agentmaster\bin` — an MSI-like per-user install with a desktop icon, a Start-menu entry, an "Open in Agentmaster" folder right-click verb, an Apps & Features / Uninstall entry, and the CLI on PATH; no admin, no package), install it to a **folder you pick**, install it **right here**, **keep it portable** (self-contained), or **decide later**. It adapts to a previous install of ours (update in place / use the installed copy), self-updates from then on, and — either way — the portable's first run also chooses its **profile folder** (remembered in a one-line `profile.path` pointer next to the exe).

A **`WindowsTerminal.exe` forwarding shim** (same icon) ships beside it, so an old shortcut, taskbar pin, script, or muscle-memory launch of the old name still lands in the one real app. The `agentmaster` command / package identity is unchanged.
- **Cross-window tab docking.** Releasing a dragged tab over **another Agentmaster window's tab strip** now moves the tab into that window at the aimed slot (with the target's own insertion caret previewing the drop), instead of always tearing out into a new window — rebuilt on the same-process, pointer-owned drag gesture that replaced the native pipeline.
- **Batch-close a folder's sessions.** The Triage-Board card / Explorer-tree session right-click **Close** — and the WT tab-strip **Close ▸** submenu — now offer **Of Same Folder** (close every live session sharing this one's effective working directory) and **Other of Same Folder** (the same batch minus this one). It's cross-window and shows a single confirm listing the tabs it will close, with no per-session prompt train.
- **Transcript Followup — a paste-ready conversation brief.** Every session copy menu (the per-tab overlay, the board/tree Copy submenu, the WT tab menu) gains **Transcript Followup**: the conversation folded per turn as `❯ <your message>` + `● <the assistant's final reply that turn>`, under a short legend — the brief you paste into a fresh follow-up session.
- **The unsent-draft pipeline, end to end.** The "3 dots" unsent-draft work matured across the board: a **MAIL button** on the tab overlay **moves** the tab's unsent draft straight into the Tests Autorunner queue (Shift+Click keeps a copy), the Manager's **compose box reconciles** with a tab's live draft (pull it in, extend it in place, or replace it via an explicit button — never silently overwriting text you composed), a **reopened session gets its remembered draft typed back** into the fresh input box (fill-only, verified, off in Settings), and **Ctrl+Shift+Up** on an empty compose box pops the last queued prompt back for editing.
- **The interrupt hold — Esc parks the autorunner until you reply.** Interrupting a turn (Esc) to say something now **parks that session's Tests Autorunner** (Semi/Full → Off) instead of firing the next queued prompt into the session you just stopped to talk to; your **next message resumes** the held mode. Setting a mode yourself meanwhile cancels the resume, and every safety pause (stop-on-error, lost-send, give-up) wins.
- **Bookmark-tag filter chips on the Triage Board.** The Sessions browser's tag chips now lead the board header too (right after **Clear**) — combining with **OR** ("show anything tagged release *or* hotfix"), persisted per window, and led by an **Untagged** chip (on by default) as the one switch that says "only tagged cards."
- **Completion toasts say which request finished.** A third toast line carries the truncated prompt whose turn just completed, so a fleet-wide pop tells you *what* came back — and the toast now stays on screen ~25 s instead of the short default.
- **The session summary lists loaded skills.** A new **Skills Loaded** section appears in the summary box on every surface that renders it, the artifacts block is reordered to **Skills Loaded → Files Created → Edited → Read**, and a session-scratchpad file is labeled `scratchpad/<name>` so it's obvious it isn't in your repo.
- **A locked terminal shows the "unavailable" cursor.** While a pane is read-only — during the draft swap's brief lock as a queued prompt is delivered, or the stock read-only toggle — the pointer over it becomes the Windows circle-with-a-slash cursor, so the pane reads as *intentionally locked* instead of the pointer simply vanishing.
- **The tab color picker opens ready.** Custom — and its advanced RGB/HSV/Hex inputs — start expanded, each toggle is remembered, and a **Use Tab Color** button seeds the picker with the color the tab already wears.
- **Copy a single prompt from the summary panel.** Right-click any numbered prompt → **Copy Prompt** for that exact prompt, verbatim.
- **The updater's "Not now" is a real choice.** The button became the default radio **"Remind me next restart,"** alongside **"Remind me tomorrow"** (the next **local** 08:00) / 3 / 7 / 30 days / skip.
- **A sensible `EDITOR` default.** Spawned sessions get `EDITOR=edit` when Microsoft's `edit.exe` is on PATH and nothing has already claimed `EDITOR` (override it in the cog's env), so tools that shell out to an editor have a working one out of the box.

### Fixes

- **Three UI-freeze classes, healed.** **(1) The Remote-Desktop theme-storm:** an RDP connect/disconnect transiently flips the system theme, which on a large window (42 tabs, measured) re-applied tab theming per-pane × per-tab re-entrantly and pegged the UI thread at 100% for 20+ minutes — now staggered, guarded fail-open, and watched by a `[ui-stall]` watchdog. **(2) The "window stops accepting clicks" wedge:** under machine-wide memory pressure XAML's event delivery could latch dead (clicks dead, the pump still answering) — the watchdog now **self-heals** it, force-pumping the stalled queue and, failing that, cleanly self-restarting with the workspace restored. **(3) Manager grind:** the hidden Manager lens no longer rebuilds the whole board+tree+plan on every notify / 30 s tick / tab switch (the "UI reacts slowly, tab switches take too long" root cause), the SemiAuto arm no longer spins a ~3 ms notify→advance loop, and a perpetual summary analyze+rebuild loop that ground the UI thread at ~80% of a core is cut.
- **The WinUI tab-drag crash class, killed.** MUX's tab-view drag lookup null-dereferenced on the first virtualized-out tab on *both* the drag-start and drop paths (`0xC0000005` inside `Microsoft.UI.Xaml.dll`) — dump-proven four times, un-closeable by any check-then-allow gate, and able to leave the app live-but-wedged. Native tab-drag is now off by construction and reorder / tear-out are a pointer-owned gesture, so neither crash site can run.
- **Orphaned console groups are reaped.** A session whose ConPTY host (`OpenConsole.exe`) was force-killed instead of closed gracefully used to live on forever with a dead console no terminal could reach (35 `claude.exe` + ~140 `node`/`cmd` children survived six days in one case). The Fleet Observer now detects and reaps such orphaned console groups after a short grace — never a hand-typed, real-Windows-Terminal, or bare-console claude (off-switch in Settings → Behavior).
- **Auto Testing delivery is atomic and verified end-to-end.** A **delivery gate** makes placing "the next prompt" one indivisible operation across the four actors that used to race over the input box (the scheduler advance, the draft swap, the Enter-retry watchdog, the pending-input scan). On top of it, a send is now **fill → read the box back → submit**: the prompt is confirmed present exactly as written before the Enter fires, a tri-state box read declines into an open menu instead of pasting into it, and a merge caught before commit is undone rather than sent. This closes a set of log-proven failures: an 8-cycle mark/decline/rollback storm, a marked-sent-twice race, restart press-storms into restored boxes, a queue that parked **invisibly** on a clarifying question with no way to release it, and — the worst — a duplicate late-stamped Stop pasting a second prompt into a still-**running** turn. A confirm-and-retry pass and a 20-second minimum send spacing mean the autorunner keeps retrying instead of pausing itself on a false "lost" signal, and never overrides a mode you set by hand.
- **Sessions no longer stick in the wrong state.** A session you **retried after an API error** could stay red **Error** for the whole retry turn (measured 35 minutes) though the agent was visibly working — it now recovers to Running on the retry. A session could sit **Running** for 17+ minutes with Claude provably idle because a single transcript line over 1 MiB fell outside the scanner's delta read — the read now grows past an oversized line. And the Enter-retry watchdog's rescue Enter can no longer submit a foreign draft.
- **Clearing a draft no longer leaves empty lines or double-sends.** The automatic input-box clear (the draft swap and the MAIL button's move) now tracks the box's visual row span and keeps going until one empty row remains, instead of stopping on the first content-kill and leaving blank rows. And the MAIL button's move uses a real discard rather than Claude's Ctrl+S *stash* — which Claude auto-restored ~0.4 s after the next submit, re-planting the moved draft (reading as a double-send).
- **Smaller fixes.** Tab hover tooltips that attached mid-hover and never opened; a two-file `/handover` losing its second successor when the seal fired mid-generation; the summary panel's context-menu handlers contained (a throw in a XAML handler is a process fail-fast, not a lost menu); the per-tab overlay's file / skill lists no longer wrap (each item is one clipped line); and turning `/handover`'s delete-after off now actually disarms an already-queued deletion.

## Install

**One command (PowerShell)** — installs 0.8.0 (admin not required: as admin it trusts the self-signed cert silently; otherwise it asks — elevate once (UAC), a no-admin per-user portable install, or cancel):
```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/Nucs/Agentmaster/agentmaster/tools/Install-Agentmaster.ps1))) -Version 0.8.0
```
Add `-Portable` (cert-free, no admin) or `-Launch` (start after install). 0.8.0 is now the default **Latest**, so a plain run (no `-Version`) also picks it up.

**Portable (no cert):** download `Agentmaster_0.8.0.0_x64.zip` (or `_arm64`), unzip anywhere, run `agentmaster.exe`. Fully self-contained — its first launch offers a per-user install or stays portable.

**MSIX bundle (self-signed):** download `Agentmaster.cer` + `Agentmaster_0.8.0.0.msixbundle`, trust the cert once (`Import-Certificate -FilePath Agentmaster.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople`, admin), then `Add-AppxPackage .\Agentmaster_0.8.0.0.msixbundle`.

Runs as **`agentmaster`** / Start menu **Agentmaster**. Upgrading keeps your data (your existing `%USERPROFILE%\.agentmaster` carries over). Requires Windows 10 2004+ (19041), x64 or arm64, with [Claude Code](https://www.anthropic.com/claude-code) (`claude`) — and optionally Codex — on `PATH`. Built on Windows Terminal v1.24.2372 (MIT).
