## Agentmaster 0.7.9-prerelease

**0.7.9 is a pre-release** consolidating everything since the 0.7.7 pre-release — the 0.7.8 nightly plus a large final batch — on top of the 0.7.0 stable. The Agent Manager moves behind the tab strip's **Home** button and a **fleet side panel** docks beside your terminal; the prompt queue, renamed the **Prompt Queue Runner**, now ships in every build instead of Debug Mode only; **presets** launch Claude Code on other models and providers (OpenRouter, Xiaomi MiMo, NanoGPT, your own RunPod endpoint, any Anthropic-compatible URL); the Sessions page gains an **AI search** that understands what you are looking for; and **Show Transcript** renders any conversation as Markdown at five detail levels. Underneath, it fixes a launch that could hang forever with no window, a crash on a mouse move over a just-opened tab, an 8-hour freeze on a tab switch, sessions reading the wrong state, hooks timing out at launch and exit, and much of the UI-thread cost of a large fleet. Enable **Settings → Updates → "Allow pre-release versions"** to receive it automatically, or install from the assets below. The stable **0.7.0** remains the default Latest for everyone else.

## New

- **The Agent Manager is a page behind the Home button.** The pinned, non-closable tab 0 is gone: the Triage Board, Explorer Tree and Prompt Queue open from the tab strip's **Home** button (left of the `<` scroll arrow), and clicking any tab, **Jump Back**, a card double-click, a toast click or Ctrl+Tab leaves the page. A window can now hold zero tabs — closing the last tab, deactivating the focused one, or closing onto a strip of dormant tabs shows the page instead of closing the window or waking a session — and a window closed while on the Manager reopens on it.
- ⚠️ **Alt+Left and Ctrl+Home are back to their Windows Terminal defaults.** **Alt+Left** moves pane focus left again (it jumped to the Manager tab) and **Ctrl+Home** is unbound again (it toggled the Manager), so both reach your shell and Claude exactly as in stock Windows Terminal. Home and Jump Back are the way in and out.
- **A fleet side panel beside the terminal.** A panel that belongs to the window, not to any tab, docks **left** of the terminal (⇄ flips it): this window's session cards on top — state dot, folder color, unsent-draft dots, timing, tag ribbons, a filter box, the board's sort, and a per-window **LOCAL / GLOBAL** toggle — over the full summary of the session you are working in. Clicking a card peeks at another session until you click back into the terminal; ⌖ (on by default) scrolls the list to the selected tab's card; **Sum** hides the summary so the cards fill the panel, and each card then shows the tab's rich session card beside the panel on hover; and **+** opens the Agent Manager's launch row in a card right at the click. Both splitters drag-resize per window (the last resize seeds new windows), and « collapses the panel to a thin strip.
- ⚠️ **The prompt queue ships in every build, as the Prompt Queue Runner.** The Tests Autorunner and its Auto Testing pane — until now only in dev builds or with Debug Mode on — are renamed the **Prompt Queue Runner** and the **Prompt Queue** and are part of every release: queue prompts for a session and each one is sent when the previous turn completes. A session has two modes, **Paused** and **Auto** (Semi-auto and its confirm are gone); the toolbar's global Pause is one state that every window shows, and each tab's badge then reads, for example, "Auto (Off globally)". An automatic send now waits until the session has held a ready state for 40 s, restarting on every status change, and never types into a parked or not-yet-started tab — the queue resumes when the tab starts. New sessions start in **Auto** (change the default under **Settings → Prompt Queue Runner**), so a prompt still Pending from an earlier Debug Mode run, or a `/handover` briefing that was never delivered, is now sent once its session is open and settled.
- **Presets — Claude Code on other models and providers.** Named presets appear after a separator in every **Open New Session Here** / **Fork session** menu and the Launch button's hover menu: MiMo Pro / Flash, Kimi K3, Qwen3.8 2.4T and GLM-5.3 through OpenRouter; MiMo through Xiaomi's own API; MiMo V2.6 Flash, GLM-5.3 Flash and DeepSeek V4.1 Flash through NanoGPT; a model on your own RunPod vLLM endpoint; or any custom Anthropic-compatible endpoint. The list starts empty — **Settings → Presets → TEMPLATES** adds a template with one click (or every tested one at once), and until you do, every launch menu offers **Add presets…**. Each field inherits from Agentmaster's env, then Windows', then the template (shown as gray placeholders); keys are kept in Windows Credential Manager and handed only to that one `claude`; a session keeps its preset through resume, restart, fork and `/handover`; and a preset that can't launch is refused, never silently downgraded to your Claude login. Templates marked "not tested yet" (Xiaomi, NanoGPT, RunPod) are added only by their own Add.
- **AI search in the Sessions page.** An **AI** toggle inside the search box turns it into a request line — type "the session where I fixed the tab drag crash" and press Enter: a hosted **Sonnet 5.5** runs the page's own search, fills the table with the sessions that fit, best match first, and states its answer in one sentence under the header. A follow-up ("only the open ones") refines the list, Escape stops a request, and ⊘ starts over. It drives one hidden `claude.exe` per Agentmaster process on your own Claude Code login — never listed among your sessions, compacting itself at 500K tokens, and ended 10 minutes after no page uses it (the conversation then resumes from a digest).
- **Show Transcript — any conversation as a reading view.** **Show Transcript** (below Copy in every session menu) renders the conversation as Markdown in a card over the window, one tab per detail level, opening at the level you last picked in any window. Each turn's tool calls fold into one summary row ("▸ 4 tool calls: Bash ×3, Write") with **Expand all**, every "session N" of a forked or restarted chain links to that session's heading, and ↵ toggles line wrapping. Esc, a click outside or a tab switch closes it.
- **Copy ▸ Transcript at five detail levels.** Every session copy menu's **Transcript ▸** copies the conversation as Markdown at **Minimal** (your messages and each final reply) · **Compact** (+ compactions, your answers, slash commands, each subagent's brief and report) · **Default** (+ every tool call on one line) · **Full** (+ each command, its first output line, durations) · **Max** (+ every written file's content) — including the sessions it was forked or restarted from and the subagents it spawned. It replaces the flat Transcript and Transcript Followup items.
- **The summary shows the whole conversation.** A session's summary now lists every earlier session it continues — a fork's parent, a plan-mode restart, a `/clear` predecessor, a `/handover` origin — numbered straight through as one conversation, with a thin separator after each earlier part (click it to copy that session's id); the ⏮ toggle hides them.
- **Unread work on the taskbar.** A red number on Agentmaster's taskbar button counts the sessions waiting for you — exactly the tabs whose status dot wears the red flash ring, across every window — and the taskbar and Alt+Tab preview of each window holding an unread tab gets a frame in the flash-ring color until you've read it. A turn that finishes in the selected tab of a background window now rings and counts until you return to that window. Both switches are under **Settings → Notifications → TASKBAR**.
- **Rendering settings.** **Settings → Behavior → RENDERING** adds **Software rendering** — every terminal drawn on the CPU instead of the GPU, applied live in every window — the escape hatch from the NVIDIA driver's ~62-terminal limit, past which a new tab could stay black; and tabs you can't see now stop drawing and give back their GPU memory after 60 s hidden (both on by default, the delay adjustable).
- **Tab size.** **Settings → Tabs & Overlay → TAB SIZE** sets the tab width mode (Windows Terminal's own setting, Equal width, Fit to title or Compact), the minimum and maximum width, the title's font size and weight, and the minimum height, live in every window.
- **Deactivate ▸ gets the Close submenu's scopes.** Beside Deactivate Tab / Other Tabs / All Tabs come **Tabs to the Left**, **Tabs to the Right**, **Of Same Folder** and **Other of Same Folder** — the folder scopes reach every window. Unlike Close they ask nothing first, and a turn still running in a parked session is cut off.
- **Unsent prompts travel with you.** A fork types the source's unsent prompt into its own box (never sent), including every `[Pasted text #N +M lines]` block, rebuilt from the real pasted content Agentmaster now remembers per session; **Copy Current Prompt** likewise hands over the pasted text instead of the label. **Settings → Sessions → "Copy my unsent prompt into a forked session"** (on by default).
- **Sorting and cards.** A **MOST RECENT** sort (board, side panel, tree) keys only on turn boundaries, so a session grinding through tool calls or a background team no longer floats above the one whose turn just started or ended; a new session or fork now starts at the top; and the timing line reads "created 4d1h, active 2m4s ago".
- **"Specify a model…" remembers your last pick.** The prompt opens pre-filled with the model you last committed — in every window and after a restart — and Enter / Escape now work in its box. The Launch folder picker also grows with the window, up to 90% of its height.

## Fixes

- **A launch that hung forever with no window.** The NVIDIA driver's initialization could deadlock against the first known-folder lookup at startup — no window appeared, and every relaunch silently failed. The folders are now resolved before the GPU is touched, and a watchdog ends a hung launch after 25 s so the next one can start.
- **A crash on a mouse move over a just-opened tab.** After a fork (or any new tab), a mouse move could reach the terminal before it had a text buffer and crash the app. A terminal now starts in its first sizing pass and ignores mouse input until it has started.
- **An 8-hour UI freeze on a tab switch.** Switching onto a tab whose conversation repeated a prompt's opening words hundreds of times could spin the summary jump resolver forever; it is bounded now, and that input resolves in 3 ms.
- **A slow UI on large fleets.** On a 555-tab window the UI thread was busy 43–60% of a core, largely redrawing for animations. The ambient animations — the unsent-draft dots, the spark crown, the unread blink — now run on the Composition API, so no XAML storyboard keeps a 60 Hz full-tree frame walk going; the side panel edits its cards in place instead of re-creating them; periodic engine work copies only what it reads; never-opened tabs no longer run a handler on every layout pass; the Tags panel opens at once (it read 2,000+ files on the UI thread, over 5 s); and the transcript scanner, which re-walked every project folder on every pass (~35% of a core), is now driven by a single file-system watch.
- **Sessions reading the wrong state.** A session no longer strands **Running** for hours after a turn ended quietly (the reader parked mid-history on a large transcript); no longer flickers Running → Waiting → Running on ~29% of prompts (the scanner read the previous turn's end before the new prompt reached the transcript); and a turn cut off by a crash or shutdown now reads **Error** instead of a ready Idle — the queue used to send its next prompt straight past it — returning to Running when the turn resumes. A compaction no longer drops a running session to Idle.
- **Hooks timing out at launch and exit.** Every hook ran through Git Bash plus your `BASH_ENV` (measured at up to 15 s) while Claude waited, and Claude's 1.5 s SessionEnd budget cancelled deliveries. On Claude Code 2.1.139+ the forwarder runs PowerShell directly (median 0.36 s), every hook carries a timeout, and SessionEnd gets 5 s.
- **Claude Code's Ctrl+G: "Edit quit unexpectedly (exit code 1)".** Past 8,191 characters of PATH, cmd.exe finds no command at all — and Claude runs its editor through cmd.exe. Agentmaster now trims the copy of PATH it hands each session (duplicates first, then only directories that provably don't exist); a healthy PATH and your registry are never touched.
- **Prompts Claude Code 2.1.277+ refused to submit, and garbled Hebrew.** Newer Claude cancels an Enter when the box holds an "invisible" character; everything Agentmaster types is now cleaned with Claude's exact, context-sensitive rule first (emoji, Indic and Persian joiners and a Hebrew line's direction marks survive). Non-ASCII prompts no longer arrive garbled (`שלום` came out `╫⌐╫£╫ò╫¥` and was recorded twice), and a non-ASCII Windows user name no longer breaks hook delivery.
- **Deactivate and Restart unbinding tabs.** A Deactivate could turn every parked tab into a plain PowerShell tab, and half of the Restarts measured were archived seconds later, because the dying claude's last signals re-stamped the record. A parked tab is now exactly a window-restored tab — entering it resumes the conversation — the closing claude's late signals are ignored, and the tab strip stays where it was.
- **The tab strip.** Selecting a far-off tab scrolls the strip to it; a tab opened from another tab's menu no longer scrolls the strip back to where you were; the strip can be scrolled away from the selected tab again; a long title ends in "…" inside its tab instead of running under the next one; and moving the focused tab no longer marks its neighbor read.
- **Closing a tab no longer starts another Claude.** Focus used to land on the neighbor, and a dormant neighbor then started its own `claude.exe`; focus now goes to the nearest tab that starts nothing, or to the Agent Manager page.
- **/compact, /clear and resume.** The context size updates the moment a compaction finishes, and summaries, copied transcripts, titles and prompt lists span the whole session across compactions (they hid ~99% of the pre-compaction prompts). External sessions follow a `/clear`, and a `/clear` in a managed tab keeps the tab managed, so Deactivate and Restart work on it again.
- **Summaries.** A message typed while Claude works now appears in the summary (Claude stores it as an attachment, not a user line), and a fork with no messages yet shows the conversation it was forked from — in Show Transcript, Copy, Summary and the tab hover card — instead of nothing.
- **Smaller fixes.** Unsent drafts are read under Claude's fullscreen renderer (`CLAUDE_CODE_NO_FLICKER=1` / `/tui fullscreen`) without mistaking Ctrl+G's editor for the input box, and **Send now** on a dormant tab keeps the prompt queued instead of losing it.

## Install (pre-release)

> **This is a pre-release.** It is **not** offered as an automatic update unless you enable **Settings → Updates → "Allow pre-release versions."** The stable **0.7.0** stays the default Latest.

**One command (PowerShell)** — installs 0.7.9-prerelease (admin not required: as admin it trusts the self-signed cert silently; otherwise it asks — elevate once (UAC), a no-admin per-user portable install, or cancel):
```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/Nucs/Agentmaster/agentmaster/tools/Install-Agentmaster.ps1))) -Version 0.7.9-prerelease
```
Add `-Portable` (cert-free, no admin) or `-Launch` (start after install).

**Portable (no cert):** download `Agentmaster_0.7.9.0_x64.zip` (or `_arm64`), unzip anywhere, run `agentmaster.exe`. Fully self-contained — its first launch offers a per-user install or stays portable.

**MSIX bundle (self-signed):** download `Agentmaster.cer` + `Agentmaster_0.7.9.0.msixbundle`, trust the cert once (`Import-Certificate -FilePath Agentmaster.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople`, admin), then `Add-AppxPackage .\Agentmaster_0.7.9.0.msixbundle`.

Runs as **`agentmaster`** / Start menu **Agentmaster**. Upgrading keeps your data (your existing `%USERPROFILE%\.agentmaster` carries over). Requires Windows 10 2004+ (19041), x64 or arm64, with [Claude Code](https://www.anthropic.com/claude-code) (`claude`) — and optionally Codex — on `PATH`. Built on Windows Terminal v1.24.2372 (MIT).
