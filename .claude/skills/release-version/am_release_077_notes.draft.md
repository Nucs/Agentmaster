## Agentmaster 0.7.7-prerelease

**0.7.7 is a pre-release** consolidating the whole 0.7.x development line — the 0.7.1–0.7.6 nightlies plus a final batch — on top of the 0.7.0 stable. It is above all a **stability release**: three separate UI-freeze classes are healed (the Remote-Desktop theme-storm, a self-healing "window stops accepting clicks" dispatch wedge, and the Manager's per-notify grind), the WinUI **tab-drag crash** is killed for good, and orphaned console groups are now reaped instead of piling up. **Auto Testing delivery** was rebuilt to be atomic and verified end-to-end — a queued prompt is filled, read back, and only then submitted, so it can no longer stack, double-send, or merge into your unsent draft — and pressing **Esc now parks the autorunner** until you reply. The app binary is now **`Agentmaster.exe`**, a portable copy's first launch offers a real **MSI-like per-user install** (or stays self-contained and self-updates in place), and new tools land for managing a fleet: **Deactivate** a tab to park it dormant, **dock** a tab into another window, **batch-close** a folder's sessions, and copy a per-turn **Transcript Followup** brief. Enable **Settings → Updates → "Allow pre-release versions"** to receive it automatically, or install from the assets below. The stable **0.7.0** remains the default Latest for everyone else.

## New

- **Deactivate a tab — park a session without closing it.** A new **Deactivate ▸** tab-menu submenu (**Deactivate Tab · Other Tabs · All Tabs**, right above **Close ▸**) shuts down a session's `claude`/`codex` while the tab keeps its place, title, color, queue, and autorunner — exactly the dormant, waiting-for-focus state a freshly reopened window's tabs sit in. Focusing or activating the tab resumes the conversation. It's the non-destructive sibling of Close: park it instead of ending it, with no confirm.
- **A portable copy installs like an app — or stays portable.** A portable (unzipped) copy's **first launch now asks where Agentmaster should live**: install it to your **user folder** (`%USERPROFILE%\.agentmaster\bin` — an MSI-like per-user install with a desktop icon, a Start-menu entry, an "Open in Agentmaster" folder right-click verb, an Apps & Features / Uninstall entry, and the CLI on PATH; no admin, no package), install it to a **folder you pick**, install it **right here**, **keep it portable** (self-contained), or **decide later**. It adapts to a previous install of ours (update in place / use the installed copy), self-updates from then on, and — either way — the portable's first run also chooses its **profile folder** (remembered in a one-line `profile.path` pointer next to the exe).
- **The app binary is now `Agentmaster.exe`.** The shipped executable is renamed from `WindowsTerminal.exe` to `Agentmaster.exe` project-wide — so Task Manager, the portable zip's launch target, and the defterm/toast COM servers all say Agentmaster. A **`WindowsTerminal.exe` forwarding shim** (same icon) ships beside it, so an old shortcut, taskbar pin, script, or muscle-memory launch of the old name still lands in the one real app. The `agentmaster` command / package identity is unchanged.
- **Cross-window tab docking.** Releasing a dragged tab over **another Agentmaster window's tab strip** now moves the tab into that window at the aimed slot (with the target's own insertion caret previewing the drop), instead of always tearing out into a new window — rebuilt on the same-process, pointer-owned drag gesture that replaced the native pipeline.
- **Batch-close a folder's sessions.** The Triage-Board card / Explorer-tree session right-click **Close** — and the WT tab-strip **Close ▸** submenu — now offer **Of Same Folder** (close every live session sharing this one's effective working directory) and **Other of Same Folder** (the same batch minus this one). It's cross-window and shows a single confirm listing the tabs it will close, with no per-session prompt train.
- **Transcript Followup — a paste-ready conversation brief.** Every session copy menu (the per-tab overlay, the board/tree Copy submenu, the WT tab menu) gains **Transcript Followup**: the conversation folded per turn as `❯ <your message>` + `● <the assistant's final reply that turn>`, under a short legend — the brief you paste into a fresh follow-up session.
- **The unsent-draft pipeline, end to end.** The "3 dots" unsent-draft work matured across the board: a **MAIL button** on the tab overlay **moves** the tab's unsent draft straight into the Tests Autorunner queue (Shift+Click keeps a copy), the Manager's **compose box reconciles** with a tab's live draft (pull it in, extend it in place, or replace it via an explicit button — never silently overwriting text you composed), a **reopened session gets its remembered draft typed back** into the fresh input box (fill-only, verified, off in Settings), and **Ctrl+Shift+Up** on an empty compose box pops the last queued prompt back for editing.
- **The interrupt hold — Esc parks the autorunner until you reply.** Interrupting a turn (Esc) to say something now **parks that session's Tests Autorunner** (Semi/Full → Off) instead of firing the next queued prompt into the session you just stopped to talk to; your **next message resumes** the held mode. Setting a mode yourself meanwhile cancels the resume, and every safety pause (stop-on-error, lost-send, give-up) wins.
- **Bookmark-tag filter chips on the Triage Board.** The Sessions browser's tag chips now lead the board header too (right after **Clear**) — combining with **OR** ("show anything tagged release *or* hotfix"), persisted per window, and led by an **Untagged** chip (on by default) as the one switch that says "only tagged cards."
- **Completion toasts say which request finished.** A third toast line carries the truncated prompt whose turn just completed, so a fleet-wide pop tells you *what* came back — and the toast now stays on screen ~25 s instead of the short default.
- **The session summary lists loaded skills.** A new **Skills Loaded** section appears in the summary box on every surface that renders it, the artifacts block is reordered to **Skills Loaded → Files Created → Edited → Read**, and a session-scratchpad file is labeled `scratchpad/<name>` so it's obvious it isn't in your repo.
- **A locked terminal shows the "unavailable" cursor.** While a pane is read-only — during the draft swap's brief lock as a queued prompt is delivered, or the stock read-only toggle — the pointer over it becomes the Windows circle-with-a-slash cursor, so the pane reads as *intentionally locked* instead of the pointer simply vanishing.
- **The tab color picker opens ready.** Custom — and its advanced RGB/HSV/Hex inputs — start expanded, each toggle is remembered, and a **Use Tab Color** button seeds the picker with the color the tab already wears.
- **Copy a single prompt from the summary panel.** Right-click any numbered prompt → **Copy Prompt** for that exact prompt, verbatim.
- **The updater's "Not now" is a real choice.** The button became the default radio **"Remind me next restart,"** alongside **"Remind me tomorrow"** (the next **local** 08:00) / 3 / 7 / 30 days / skip.
- **A sensible `EDITOR` default.** Spawned sessions get `EDITOR=edit` when Microsoft's `edit.exe` is on PATH and nothing has already claimed `EDITOR` (override it in the cog's env), so tools that shell out to an editor have a working one out of the box.

## Fixes

- **Three UI-freeze classes, healed.** **(1) The Remote-Desktop theme-storm:** an RDP connect/disconnect transiently flips the system theme, which on a large window (42 tabs, measured) re-applied tab theming per-pane × per-tab re-entrantly and pegged the UI thread at 100% for 20+ minutes — now staggered, guarded fail-open, and watched by a `[ui-stall]` watchdog. **(2) The "window stops accepting clicks" wedge:** under machine-wide memory pressure XAML's event delivery could latch dead (clicks dead, the pump still answering) — the watchdog now **self-heals** it, force-pumping the stalled queue and, failing that, cleanly self-restarting with the workspace restored. **(3) Manager grind:** the hidden Manager lens no longer rebuilds the whole board+tree+plan on every notify / 30 s tick / tab switch (the "UI reacts slowly, tab switches take too long" root cause), the SemiAuto arm no longer spins a ~3 ms notify→advance loop, and a perpetual summary analyze+rebuild loop that ground the UI thread at ~80% of a core is cut.
- **The WinUI tab-drag crash class, killed.** MUX's tab-view drag lookup null-dereferenced on the first virtualized-out tab on *both* the drag-start and drop paths (`0xC0000005` inside `Microsoft.UI.Xaml.dll`) — dump-proven four times, un-closeable by any check-then-allow gate, and able to leave the app live-but-wedged. Native tab-drag is now off by construction and reorder / tear-out are a pointer-owned gesture, so neither crash site can run.
- **Orphaned console groups are reaped.** A session whose ConPTY host (`OpenConsole.exe`) was force-killed instead of closed gracefully used to live on forever with a dead console no terminal could reach (35 `claude.exe` + ~140 `node`/`cmd` children survived six days in one case). The Fleet Observer now detects and reaps such orphaned console groups after a short grace — never a hand-typed, real-Windows-Terminal, or bare-console claude (off-switch in Settings → Behavior).
- **Auto Testing delivery is atomic and verified end-to-end.** A **delivery gate** makes placing "the next prompt" one indivisible operation across the four actors that used to race over the input box (the scheduler advance, the draft swap, the Enter-retry watchdog, the pending-input scan). On top of it, a send is now **fill → read the box back → submit**: the prompt is confirmed present exactly as written before the Enter fires, a tri-state box read declines into an open menu instead of pasting into it, and a merge caught before commit is undone rather than sent. This closes a set of log-proven failures: an 8-cycle mark/decline/rollback storm, a marked-sent-twice race, restart press-storms into restored boxes, a queue that parked **invisibly** on a clarifying question with no way to release it, and — the worst — a duplicate late-stamped Stop pasting a second prompt into a still-**running** turn. A confirm-and-retry pass and a 20-second minimum send spacing mean the autorunner keeps retrying instead of pausing itself on a false "lost" signal, and never overrides a mode you set by hand.
- **Sessions no longer stick in the wrong state.** A session you **retried after an API error** could stay red **Error** for the whole retry turn (measured 35 minutes) though the agent was visibly working — it now recovers to Running on the retry. A session could sit **Running** for 17+ minutes with Claude provably idle because a single transcript line over 1 MiB fell outside the scanner's delta read — the read now grows past an oversized line. And the Enter-retry watchdog's rescue Enter can no longer submit a foreign draft.
- **Clearing a draft no longer leaves empty lines or double-sends.** The automatic input-box clear (the draft swap and the MAIL button's move) now tracks the box's visual row span and keeps going until one empty row remains, instead of stopping on the first content-kill and leaving blank rows. And the MAIL button's move uses a real discard rather than Claude's Ctrl+S *stash* — which Claude auto-restored ~0.4 s after the next submit, re-planting the moved draft (reading as a double-send).
- **Smaller fixes.** Tab hover tooltips that attached mid-hover and never opened; a two-file `/handover` losing its second successor when the seal fired mid-generation; the summary panel's context-menu handlers contained (a throw in a XAML handler is a process fail-fast, not a lost menu); the per-tab overlay's file / skill lists no longer wrap (each item is one clipped line); and turning `/handover`'s delete-after off now actually disarms an already-queued deletion.

## Install (pre-release)

> **This is a pre-release.** It is **not** offered as an automatic update unless you enable **Settings → Updates → "Allow pre-release versions."** The stable **0.7.0** stays the default Latest.

**One command (PowerShell)** — installs 0.7.7-prerelease (admin not required: as admin it trusts the self-signed cert silently; otherwise it asks — elevate once (UAC), a no-admin per-user portable install, or cancel):
```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/Nucs/Agentmaster/agentmaster/tools/Install-Agentmaster.ps1))) -Version 0.7.7-prerelease
```
Add `-Portable` (cert-free, no admin) or `-Launch` (start after install).

**Portable (no cert):** download `Agentmaster_0.7.7.0_x64.zip` (or `_arm64`), unzip anywhere, run `agentmaster.exe`. Fully self-contained — its first launch offers a per-user install or stays portable.

**MSIX bundle (self-signed):** download `Agentmaster.cer` + `Agentmaster_0.7.7.0.msixbundle`, trust the cert once (`Import-Certificate -FilePath Agentmaster.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople`, admin), then `Add-AppxPackage .\Agentmaster_0.7.7.0.msixbundle`.

Runs as **`agentmaster`** / Start menu **Agentmaster**. Upgrading keeps your data (your existing `%USERPROFILE%\.agentmaster` carries over). Requires Windows 10 2004+ (19041), x64 or arm64, with [Claude Code](https://www.anthropic.com/claude-code) (`claude`) — and optionally Codex — on `PATH`. Built on Windows Terminal v1.24.2372 (MIT).
