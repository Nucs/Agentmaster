## Agentmaster 0.7.8-prerelease-nightly (nightly)

> ⚠️ **NIGHTLY build** — an unstable development version. It may have memory leaks, CPU issues, and crashes. Install it only to help test, and be willing to have your work interrupted.

**The Agent Manager moves behind the Home button, a fleet side panel docks beside your terminal, and the taskbar counts what is waiting for you.** Three weeks of mainline since the 0.7.7 pre-release (25 user-facing commits): the Manager is no longer a pinned tab 0 but a page the tab strip's **Home** button opens, a new **side panel** keeps this window's session cards and the focused session's summary next to the terminal, and a red **unread count** on the taskbar button tells you how many sessions finished while you looked away. Underneath, this nightly fixes an 8-hour UI freeze on a tab switch, sessions stranded **Running** hours after their turn ended, hooks timing out at launch and exit, a scanner that burned a third of a core, Claude Code's Ctrl+G editor failing with "exit code 1", and prompts that Claude Code 2.1.277+ silently refused to submit. Nightlies are **not** offered to pre-release users — enable **Settings → Updates → "Allow updating to nightly builds (unstable)"** (a warning confirm gates it) or install from the assets below. The stable **0.7.0** remains Latest for everyone else.

## New & changed

- **The Agent Manager is a page behind the Home button.** The pinned, non-closable tab 0 is gone: the Triage Board, Explorer Tree and Auto Testing now open from the tab strip's **Home** button (left of the `<` scroll arrow), painted as the active entry while the page is up; clicking any tab, **Jump Back**, a card double-click, a toast click or Ctrl+Tab leaves it. A window can now hold zero tabs — closing the last tab, deactivating the focused one, or closing onto a strip where every other tab is dormant shows the page instead of closing the window or waking a session — and a window closed while on the Manager reopens on it. With the tab row hidden (focus mode, or fullscreen), the page is reachable again once the row is back.
- ⚠️ **Alt+Left and Ctrl+Home are back to their Windows Terminal defaults.** **Alt+Left** moves pane focus left again (it used to jump to the Manager tab), and **Ctrl+Home** is unbound again (it toggled the Manager), so both reach your shell and Claude exactly as in stock Windows Terminal. The Home and Jump Back buttons are the way in and out; Alt+Right still switches to the next tab.
- **A fleet side panel beside the terminal.** A new panel — part of the window, not of any tab — docks **left** of the terminal (⇄ flips it). The top lists this window's session cards: each shows its state dot, folder color, unsent-draft dots, timing and bookmark-tag ribbons, with a filter box, the board's sort order, and a **LOCAL / GLOBAL** toggle (remembered per window) that widens the list to every window. The bottom shows the full summary of the session you are working in. Clicking a card PEEKS at another session until you click back into the terminal, and the ⌖ toggle (on by default) scrolls the list to the selected tab's card. Both splitters drag-resize per window, and the last resize becomes the default for new windows; « collapses the panel to a thin strip.
- **An unread count on the taskbar button.** A red number on Agentmaster's taskbar icon counts the sessions waiting for you — exactly the tabs whose status dot wears the red flash ring, across every window — and drops as you visit each one. With it, a turn that finishes in the **selected tab of a background window** now rings (and counts) until you switch back to that window, where it used to count as already seen. Turn it off under **Settings → Notifications → TASKBAR**.
- **A fork brings your unsent prompt along.** Forking a session (the tab's **Fork session**, the board/tree Fork, the Sessions page's Fork here) types the source's unsent input-box text into the fork's box — never sent — including every `[Pasted text #N +M lines]` block, rebuilt from the real pasted content Agentmaster now remembers per session (Claude itself writes a paste to disk only when you submit it). Text you type into the fork first always wins. **Settings → Sessions → "Copy my unsent prompt into a forked session"** (on by default).
- **Copy hands over the pasted text.** **Copy Current Prompt** (and the Auto Testing row menu's **Copy**) now puts the pasted content on the clipboard instead of a `[Pasted text #N +M lines]` label — whenever it can prove which paste the label stands for; otherwise the text is copied exactly as shown.
- **A MOST RECENT sort.** The Triage Board, the side panel and the Explorer Tree gain an order keyed only on turn boundaries — when you last sent a turn, or the assistant last finished one — so a session grinding through tool calls, subagents or a background team no longer floats above the one whose turn just started or ended. MOST ACTIVE is unchanged.
- **The Launch folder picker uses the window.** The path-picker drop-down under the Launch box grows up to 90% of the window's height (it was a fixed 380 px) and re-fits when you resize the window.

## Fixes

- **An 8-hour UI freeze on a tab switch.** Switching onto a tab whose conversation repeated a prompt's opening words hundreds of times could spin the summary-panel jump resolver forever — a standard-library search returned a position past the limit it was given — freezing the window until a restart. The loop is now bounded, and that exact input resolves in 3 ms.
- **Sessions stranded "Running" after their turn ended.** A large transcript was read in 1 MiB windows, but only when the file grew — so a turn that ended quietly (one Claude aborted right after a `--resume`, measured) left the reader parked mid-history and the card Running for 7+ hours. The reader now keeps catching up on an unchanged file, starts at the tail of a large history, and judges nothing until it has caught up.
- **Hooks timing out at launch and exit.** Every hook ran through Git Bash plus whatever your `BASH_ENV` runs — measured at up to 15 s — while Claude waited on it at session start, on every prompt and at every turn end, and Claude's 1.5 s SessionEnd budget cancelled deliveries mid-flight. On Claude Code 2.1.139+ the hook forwarder now runs PowerShell directly (median 0.36 s, was 0.97 s warm), every hook carries a timeout, SessionEnd gets 5 s (a budget Claude shares with your own SessionEnd hooks, which used to be cut at 1.5 s), and a turn end takes Claude's final message from the hook itself instead of re-reading the transcript.
- **The scanner's CPU burn.** The transcript scanner re-walked every Claude project folder for never-prompted sessions on every pass — about 35% of a core on a 60-session fleet. It is now event-driven, woken by a single file-system watch on Claude's projects folder, so a quiet session costs nothing between changes.
- **Claude Code's Ctrl+G: "Edit quit unexpectedly (exit code 1)".** Once your PATH grows past 8,191 characters, cmd.exe cannot find ANY command — and Claude runs its Ctrl+G editor through cmd.exe, so the editor never even started. When the PATH is near that limit, Agentmaster now trims the copy it hands every session: duplicates first, then only directories that provably don't exist, never a live one. A healthy PATH is untouched, and your registry PATH is never written.
- **Prompts Claude Code 2.1.277+ refused to submit.** Newer Claude cancels an Enter when the box holds an "invisible" character (zero-width, bidi marks, variation selectors…) and leaves the text sitting there — which stalled a /handover briefing, a restored draft or a queued prompt one Enter short. Everything Agentmaster types into a Claude box is now cleaned with Claude's exact rule first (context-sensitive, so emoji, Indic and Persian joiners and a Hebrew line's direction marks survive), and every prompt comparison ignores those characters.
- **Hebrew and other non-ASCII prompts arrived garbled.** The hook forwarder decoded Claude's UTF-8 in the console code page (`שלום` came out `╫⌐╫£╫ò╫¥`, and such prompts were recorded twice); it now reads UTF-8, and the forwarder script carries a BOM so a non-ASCII Windows user name no longer breaks hook delivery.
- **/compact, /clear and resume.** A compaction no longer drops a running session to Idle (where it also looked ready for the next queued prompt), the context size updates the moment a compaction finishes, and the summary panel, copied transcripts, titles and prompt lists now span the whole session across compactions — they used to hide ~99% of the pre-compaction prompts. External sessions follow a `/clear`, and a `/clear` in a managed tab keeps the tab managed, so Deactivate and Restart work on it again.
- **Closing a tab no longer starts another Claude.** Closing the focused tab handed focus to its neighbor, and a restored (dormant) neighbor then started its own `claude.exe` about 0.4 s later — so the process count never dropped. Focus now goes to the nearest tab that starts nothing, or to the Agent Manager page.
- **Unsent drafts under Claude's fullscreen renderer.** With `CLAUDE_CODE_NO_FLICKER=1` or `/tui fullscreen`, Claude draws in the terminal's alternate screen; the unsent-draft reader now reads it there too, while a full-screen app launched from a Claude tab (Ctrl+G's editor, a pager) is never mistaken for the input box.
- **Selecting a far tab scrolls the strip to it.** On a long tab strip, a card click, Jump Back, a toast click, Ctrl+Tab or a close switched to a tab scrolled far off without the strip following; it now scrolls there, and a tab already on screen never slides out from under your pointer. Moving the focused tab no longer marks its neighbor as read (clearing its flash ring), and a close now gives the tab it lands on the same focus handling as a switch.

## Install (nightly)

> ⚠️ **This is a nightly.** It is offered as an automatic update **only** if you enable **Settings → Updates → "Allow updating to nightly builds (unstable)"** — enabling "Allow pre-release versions" is *not* enough. The stable **0.7.0** stays the default Latest.

**One command (PowerShell)** — installs this nightly (admin not required: as admin it trusts the self-signed cert silently; otherwise it asks — elevate once (UAC), a no-admin per-user portable install, or cancel):
```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/Nucs/Agentmaster/agentmaster/tools/Install-Agentmaster.ps1))) -Version 0.7.8-prerelease-nightly
```
Add `-Portable` (cert-free, no admin) or `-Launch` (start after install).

**Portable (no cert):** download `Agentmaster_0.7.8.0_x64.zip` (or `_arm64`), unzip anywhere, run `agentmaster.exe`. Fully self-contained — its first launch offers a per-user install or stays portable.

**MSIX bundle (self-signed):** download `Agentmaster.cer` + `Agentmaster_0.7.8.0.msixbundle`, trust the cert once (`Import-Certificate -FilePath Agentmaster.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople`, admin), then `Add-AppxPackage .\Agentmaster_0.7.8.0.msixbundle`.

Runs as **`agentmaster`** / Start menu **Agentmaster**. Upgrading keeps your data (your existing `%USERPROFILE%\.agentmaster` carries over). Requires Windows 10 2004+ (19041), x64 or arm64, with [Claude Code](https://www.anthropic.com/claude-code) (`claude`) — and optionally Codex — on `PATH`. Built on Windows Terminal v1.24.2372 (MIT).
